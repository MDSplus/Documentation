# Homebrew / Macports

Support for Homebrew and Macports is under development, and instructions will be posted here when it is complete.

In the meantime, tarballs containing binaries built inside Homebrew and Macports environments are available for each [GitHub Release](./github-releases.md). They will be labeled `mdsplus_<version>_homebrew_arm64.tgz` and `mdsplus_<version>_macports_arm64.tgz`.

Additionally, users who only need to access remote MDSplus data with python can use [mdsthin](https://github.com/MDSplus/mdsthin).
